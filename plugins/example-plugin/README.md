# Example Plugin

这是一个示例插件，展示 Finance Skill Marketplace 插件的基本结构和开发规范。

## 功能

- `greeting` skill: 简单的问候示例

## 目录结构

```
example-plugin/
├── .claude-plugin/
│   └── plugin.json      # 插件元数据
├── skills/
│   └── greeting/
│       └── SKILL.md     # Skill 定义
└── README.md            # 插件说明
```

## 使用方式

此插件主要作为开发参考，帮助理解如何创建新的金融领域 Skill。

## 开发新 Skill 参考

1. 复制此插件目录结构
2. 修改 plugin.json 中的名称和描述
3. 根据需求编写 SKILL.md
4. 注册到 marketplace.json
